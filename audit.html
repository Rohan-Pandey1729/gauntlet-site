What it checks

Exploits
Ways to raise the reward without solving the task.
  • Answers, the verifier or the reference solution reachable from the agent's image
  • Instance generators shipped with small grading seeds, so answers can be looked up
  • Agent code run as root while the grader is readable, or a sandbox that fails open
  • Verifier imports an agent file can shadow
  • Reward files an agent can rewrite from inside its own container
  • NaN and infinity slipping past numeric checks
  • Lean proofs with sorry, extra axioms, native_decide or a weakened statement
Artifacts
Scores that measure something other than the skill the task claims.
  • Grading constants the instruction never states
  • Turn caps and short clocks that turn difficulty into throughput
  • All-or-nothing rewards that hide how close an agent got
  • Wording that triggers safety refusals instead of measuring capability
  • No reference solution, so a broken task looks like a hard one

How an audit runs

1

Read

Static rules read task.toml, the build context, the verifier and the reference solution. Nothing executes.

2

Attack

We build the image and grade four runs: do nothing, the reference solution, a planted reward hook, and a solver that tries to read the grader.

3

Gate

Ranked findings with evidence and a fix for each, as Markdown and JSON, plus an exit code that fails CI on anything you choose.
