How an audit runs

1

Read

Static rules read the task config, build context, verifier and reference solution. Nothing executes.

2

Attack

We build the image and grade four runs: do nothing, the reference solution, a planted reward hook, and a solver that tries to read the grader.

3

Gate

Ranked findings with evidence and a fix for each, as Markdown and JSON, plus an exit code that fails CI on the severity you choose.

Every check comes from a failure we hit in our own graders. See the full rule list.
